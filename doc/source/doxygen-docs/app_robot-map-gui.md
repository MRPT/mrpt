# robot-map-gui

Viewer and editor of robot-made maps stored as `.simplemap` files (a
sequence of keyframes: robot poses with their observations, see
mrpt::maps::CSimpleMap), as generated by [icp-slam](page_app_icp-slam.html),
[rbpf-slam](page_app_rbpf-slam.html) and other SLAM methods. It builds
metric maps (occupancy grids, point clouds, beacon maps, ...) from the
keyframes with a user-defined configuration, shows them in 3D, and allows
inspecting the observations of each keyframe and editing the keyframe poses.
It uses Qt5.

## Usage

    robot-map-gui [file.simplemap]

The optional argument is a `.simplemap` or `.simplemap.gz` file to open.

## Example

    robot-map-gui modules/mrpt_data/datasets/malaga-cs-fac-building.simplemap.gz

Then load a map configuration with **File > Load config** (Ctrl+E), e.g.
`modules/mrpt_data/config_files/icp-slam/icp-slam_demo_classic.ini`, to
build and display the maps.

## User interface

- **Map configuration**: the list of metric maps to build. Load it from an
  INI file (the map definitions are read from the `[MappingApplication]`
  section, as in the [icp-slam](page_app_icp-slam.html) and
  [rbpf-slam](page_app_rbpf-slam.html) config files), or define it by hand:
  **Add** / **Remove** maps (point map, occupancy grid, landmarks, beacon
  map, gas grid), edit their parameters and press **Apply**. **Save config**
  writes it to an INI file.
- **Map view**: one tab per metric map, with zoom, azimuth and elevation
  controls; the coordinates under the mouse cursor are shown below it.
  **Show all observation** draws the keyframe poses on top of the map.
- **Observations tree**: the keyframes and their observations. Selecting a
  keyframe or a range scan highlights it in the map view; selecting an image
  shows it in the **Observations viewer** panel.
- **Editing keyframes** (with **Show all observation** enabled): click on a
  keyframe pose in the map view to select it (Ctrl+click to add it to or remove it from
  the selection), drag to move the selected poses, press `Delete` to remove
  them, and change the orientation (yaw, pitch, roll) of a single selected
  pose in the **Pose direction** panel. The maps are rebuilt after each
  change, and **Undo** / **Redo** revert or repeat changes.

## Saving

**File** menu:

- **Save as simplemap** (Ctrl+S): save the (edited) keyframes, overwriting
  the opened file.
- **Save metric map representation**: save one of the metric maps in its
  default representation (e.g. image files for grid maps).
- **Save metric map in binary format**: serialize one of the metric maps.
- **Save points map as text**, **Save gridmap as PNG**.
- **Recent files**.
